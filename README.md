# Hossam Amin Abdelhamed — Full-Stack Architect Portfolio

🌐 **Live Production Portfolio:** [https://hossam-amin-portfolio.vercel.app](https://hossam-amin-portfolio.vercel.app)

Modern, high-converting developer portfolio engineered with **Next.js 15 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Framer Motion**.

## Key Features
- **Linear/Vercel-Inspired Dark/Light Theme:** Built with a dark-first aesthetic, subtle architectural grid patterns, and instant Light/Dark theme switching.
- **Services Bento Grid:** Showcases Full-Stack SaaS, Backend/API Architecture, Enterprise ERP Automation, and Database/DevOps offerings.
- **Production Engineering Case Studies:**
  - **Wahy Wa Namaa Academy:** Live production link ([wahywanamaa.com](https://wahywanamaa.com)), Vercel mirror, and GitHub repository with a 4-layer interactive architecture diagram.
  - **Makhzan Al-Neda ERP:** B2B Pharmaceutical Distribution & Inventory ERP with Client-Server FastAPI + SQLAlchemy 2.0 + ReportLab PDF engine.
  - **Wahy Platform V2:** Next.js + NestJS + Prisma ORM modular monorepo architecture.
- **Interactive System Architecture Lab:** Allows technical founders and recruiters to inspect each architectural layer under the hood.
- **Full-Stack Project Inquiry & Quote Engine:** Supports both `POST /api/contact` server logging and 1-click formatted WhatsApp inquiry dispatch (`+20 115 181 4312`).

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
